## Data sources

`webapp/stations.json` is generated by `scripts/build_stations.py` from:

- **Trenitalia GTFS** — stops served by Frecciarossa, Frecciargento and Frecciabianca, with their
  Trenitalia location ids and coordinates. Contains data from Trenitalia S.p.A., published through the
  Italian National Access Point ([CCISS MMTIS](https://www.cciss.it/nap/mmtis/public/en/catalog/Dataset/1077621)),
  converted from NeTEx to GTFS by Clément Desouche ([deryclem/trenitalia-gtfs](https://github.com/deryclem/trenitalia-gtfs)).
  Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes: only the stations
  served by Frecce trains are kept (id, coordinates for matching), renamed and merged with the sources below.
- **trenitalia.com** — the public station list behind the site's search box
  (`it.cruscotto-stations.json`), for station spellings and the Frecce flag.
- **Italo** — the public station list of the Italo booking site (`api-biglietti.italotreno.com/api/v1/stations`),
  for Italo station codes and city groups.
- **lefrecce.it** — the public location search, used once by hand to look up the Trenitalia
  "( Tutte Le Stazioni )" city-group ids.

Fares are read at run time from the public booking APIs of Trenitalia (lefrecce.it) and Italo.
TrainWatcher is a personal project, not affiliated with Trenitalia, Italo or the CCISS.
